# 🎬 Movie Application

A web-based **Movie Ticket Booking Application** developed as a college project. The application provides a simple and interactive interface for users to browse movies, view movie details, select theatres and seats, make bookings, and receive booking confirmation.

## 📌 Features

* 🏠 Home page with movie information
* 🎥 Browse available movies
* 🔍 View detailed information about movies
* 🔐 User login interface
* 🎭 Theatre selection
* 💺 Seat selection and booking
* 💳 Payment page
* 🎟️ Booking confirmation
* 📱 Responsive and user-friendly interface
* 📁 Organized HTML, CSS, and JavaScript structure

## 🛠️ Technologies Used

* **HTML5** – Structure of the web pages
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactive functionality and user interactions

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Navigate through the application using the available options.

For the best development experience, the project can also be opened using **Visual Studio Code** with the Live Server extension.

## 🎯 Project Objective

The objective of this project is to develop a simple movie ticket booking system that demonstrates the use of **HTML, CSS, and JavaScript** to create an interactive web application.
